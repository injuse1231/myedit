# MyEdit

Лёгкий редактор кода для Ubuntu в стиле VS Code. Полностью на Python + PyQt6.

## Возможности

- 4 темы в стиле VS Code (Dark+, Dark Modern, Light+, Light Modern)
- Дерево файлов с контекстным меню
- Вкладки с перетаскиванием
- Подсветка синтаксиса (Python, JS, HTML, CSS, JSON, C/C++, Bash, SQL)
- Поиск и замена, поиск по проекту
- Быстрое открытие файла и командная палитра
- Автодополнение
- Minimap
- Запуск Python (F5)
- Сохранение сессии
- Настройки
- Сворачивание блоков
- Свой gutter с номерами строк
